# Шин-сервис

Одностраничный сайт шиномонтажа в Волгограде. Статические HTML, CSS и JavaScript без внешних библиотек.

## Локальный запуск

```sh
python3 -m http.server 8000 --directory dist
```

Откройте [localhost:8000](http://localhost:8000).

## Развёртывание на Vercel

Импортируйте репозиторий `shin` в Vercel. Файл `vercel.json` указывает, что сайт находится в каталоге `dist`. Команда сборки и переменные окружения не нужны.

## Данные для заполнения

В `dist/index.html` замените цены «от ___ ₽», пометку о графике, три заглушки отзывов и места для фотографий. Форма открывает чат с готовым текстом на номер +7 905 333-34-38. Клиент отправляет сообщение сам и согласовывает время с мастерской.
